# Exercise 01: Internal LED Blinking (Blink)

In this exercise, the leds conneted to the Arduino Uno is controlled using register-level pure C programming.

### Register Implementations:
* `DDRB`: Used to set the data direction of Port B.
* `PORTB`: Used to toggle the LED by writing logic 1 (HIGH) and logic 0 (LOW) to the pins.
